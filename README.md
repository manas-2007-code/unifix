# UniFix 

UniFix is a basic campus issue reporting website made with HTML, CSS and Java Script

## Pages

- `index.html` - Login page
- `student-signup.html` - Student registration form
- `admin-signup.html` - Administration registration form
- `student-dashboard.html` - Student dashboard
- `report-issue.html` - Submit a campus complaint
- `my-complaints.html` - View and search your complaints
- `admin-dashboard.html` - Administration dashboard
- `manage-complaints.html` - Search complaints and update their status

## Code folders

- `css/style.css` - Common website colours and text
- `css/forms.css` - Login and sign-up page design
- `css/dashboard.css` - Dashboard design
- `js/common.js` - Simple storage and logout functions
- `js/auth.js` - Login and sign-up code
- `js/student.js` - Student pages and complaint submission
- `js/admin.js` - Admin pages and status updates
- `assets/unifix-logo.svg` - UniFix logo
